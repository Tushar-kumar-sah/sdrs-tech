# SDRS Tech

Official website for **SDRS Tech** (*SDRS Meta Rise Tech Private Limited*).

Building custom software, SaaS platforms, web and mobile apps, AI solutions, and cloud systems.

## Features

- **Interactive 3D WebGL Hero:** Dynamic particle sphere with pointer parallax tracking and 2D canvas fallback.
- **High Performance:** Lightweight, zero-dependency vanilla JS with smooth `requestAnimationFrame` scroll scheduling.
- **Product Showcase:** Interactive stories for **OMNIGO** (mobility and towing dispatch) and **GRABDOO** (local commerce).
- **SEO & Structured Data:** Full Schema.org JSON-LD graph, Open Graph, and Twitter metadata.
- **Direct Lead Capture:** Enquiry submission integrated directly with WhatsApp.

## Run Locally

Start a local HTTP server:

```bash
# Using Python
python -m http.server 8080

# Or using Node
npx serve
```

Then visit [http://localhost:8080/](http://localhost:8080/) in your browser.
